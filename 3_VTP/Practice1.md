# Задание на практику 1

Выбрать одну из 3-х идей, объяснить выбор, прописать для компании реализующей эту идею миссию, ценности, цель и по возможности провести сравнение с конкурентами на основе поиска в интернете реально действующих компаний. При ответе обозначить все 3 идеи, время на ответ до 3,5 минут

| **1. Creative Technologies (Креативные технологии)**                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Платформа для генерации гиперперсонализированного интерактивного контента (песни, стихи, сценарии) на основе ИИ с использованием эмоционального анализа данных пользователя.** Сервис анализирует предпочтения, историю потребления контента и даже текущее настроение пользователя через камеру/микрофон для создания уникальных произведений искусства, которые резонируют с ним на личном уровне. |
| **2. AR-студия для виртуального мерчандайзинга и примерки цифровой одежды в социальных сетях.** Технология позволяет брендам и influencers размещать интерактивные 3D-модели одежды и аксессуаров в своих постах, которые пользователи могут "примерить" на себя в AR и сразу приобрести, стирая грань между вдохновением и покупкой.                                                                     |
| **3. Децентрализованная платформа (на блокчейне) для совместного создания и монетизации цифровых коллективных произведений искусства (music, video, NFT).** Платформа автоматически распределяет роялти и права между всеми участниками креативного процесса (художники, композиторы, аниматоры) на основе смарт-контрактов, фиксирующих вклад каждого.                                                   |

| **2. Edtech (Образование)**                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. AI-ассистент-репетитор на базе генеративного ИИ, адаптирующийся под стиль обучения и знания ученика в реальном времени.** Ассистент не только объясняет темы, но и создает персонализированные задания, распознает пробелы в знаниях и использует методы микрообучения (microlearning) для их устранения, интегрируясь с популярными платформами.         |
| **2. Иммерсивная образовательная платформа на базе VR/AR для профессиональной подготовки (например, хирургии, ремонта сложного оборудования).** Платформа симулирует реальные рабочие сценарии с тактильной обратной связью, позволяя отрабатывать навыки без риска и дорогостоящих затрат, с системой оценки действий и мгновенной обратной связью.           |
| **3. Платформа для создания и продажи малых курсов (microlearning) по "гибким навыкам" (soft skills) с автоматической валидацией навыков через анализ симуляций.** Авторы создают короткие видео-курсы, а система проверяет усвоение материала через интерактивные симуляции с анализом решений AI, выдавая цифровые сертификаты, признаваемые работодателями. |

| **3. Energy (Энергетика)**                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Сервис по созданию и управлению виртуальными электростанциями (VPP) для объединения домашних аккумуляторов, электромобилей и солнечных панелей в единый пул.** Агрегатор в автоматическом режиме продает излишки энергии обратно в сеть в пиковые часы, оптимизируя нагрузку на сеть и генерируя пассивный доход для владельцев. |
| **2. AI-решение для предиктивного анализа и оптимизации энергопотребления в коммерческой недвижимости.** Система анализирует данные с IoT-датчиков, прогноз погоды и график работы здания, чтобы автоматически настраивать HVAC-системы (отопление, вентиляция, кондиционирование), сокращая затраты на энергоносители до 30%.        |
| **3. Разработка и производство модульных систем долговременного хранения энергии на основе новых химических элементов (например, железо-воздушных батарей).** Низкая стоимость материалов и длительный срок хранения энергии (100+ часов) делают такие системы идеальными для обеспечения стабильности сетей с большой долей ВИЭ.     |

| **4. Cleantech (Чистые технологии)**                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Сервис по аффинажному (чистому) извлечению лития и других ценных металлов из отработанных Li-ion аккумуляторов с помощью гидрометаллургических процессов с низким углеродным следом.** Технология позволяет замкнуть цикл производства аккумуляторов, снижая зависимость от добычи ископаемых и решая проблему токсичных отходов. |
| **2. Умные системы сбора и сортировки текстиля на основе компьютерного зрения.** Установленные в торговых центрах контейнеры автоматически сортируют одежду по типу ткани и цвету, поощряя сдачу бонусами. Данные анализируются для оптимизации логистики и дальнейшей переработки в новые материалы.                                  |
| **3. Разработка твердых (solid-state) негорючих хладагентов для систем кондиционирования и охлаждения.** Такие хладагенты не обладают парниковым эффектом и не разрушают озоновый слой, что кардинально решает проблему экологического вреда от традиционных систем HVAC.                                                              |

| **5. Robototech (Робототехника)**                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Робот-манипулятор с "компьютерным зрением" и ИИ для автоматизации сортировки и сборки в малом бизнесе (логистика, мелкое производство).** Ключевая особенность — no-code платформа для обучения, где задачи ставятся путем демонстрации жестов (kinesthetic teaching) или через AR-интерфейс, без необходимости программирования. |
| **2. Стационарные дроны для автоматизированного инвентаря и безопасности на складах.** Дроны autonomously patrol aisles, scanning barcodes and RFID tags with cameras and sensors, providing real-time inventory data and alerting to anomalies, integrating with existing WMS.                                                        |
| **3. Мобильные роботы-курьеры для доставки "последней мили" в плотных городских условиях.** Роботы на электрической тяге, способные безопасно перемещаться по тротуарам и пешеходным зонам, доставляя еду и небольшие посылки, с полностью автоматической работой через приложение для клиентов.                                       |

| **6. Life Sciences (Науки о жизни)**                                                                                                                                                                                                                                                                                                |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Платформа для удаленного управления хроническими заболеваниями (диабет, гипертония) с помощью ИИ и данных с носимых устройств.** Алгоритм анализирует показатели в реальном времени, прогнозирует риски осложнений и дает персональные рекомендации по терапии, питанию и образу жизни, connecting patients and doctors.       |
| **2. Сервис персональized питания и добавок на основе глубокого анализа микробиома кишечника.** Пользователь получает набор для забора пробы, которую анализируют в lab. На основе результатов AI формирует индивидуальные рекомендации по питанию и производит персонализированные добавки (например, с использованием 3D-печати). |
| **3. Разработка биоразлагаемых имплантатов с контролируемым сроком рассасывания для травматологии.** Имплантаты (например, винты, пластины) фиксируют переломы и постепенно рассасываются по мере восстановления кости, исключая необходимость повторной операции по удалению и снижая риск отторжения.                             |

Agritech и Foodtech**                                                                                                                                                                                                                                                                                                           |

Разработка и производство растительных аналогов жира и мяса сложной структуры (например, стейков с прожилками) с помощью технологии 3D-биопринтинга.** Позволяет точно воспроизводить текстуру и вкусовые ощущения от настоящего мяса, appealing to flexitarians и устойчивое производство.                                     |

ITC (Информационно-коммуникационные технологии)**                                                                                                                                                                                                                                                                           |

| **3. Low-code/no-code платформа для быстрой разработки и развертывания сложных enterprise-приложений (ERP, CRM) с глубокой интеграцией AI-модулей.** Позволяет бизнес-аналитикам без навыков кодирования собирать гибкие и адаптивные системы под конкретные нужды компании, drastically reducing time-to-market.                |
