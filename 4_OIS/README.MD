1. Найти любой случай, который нарушает чьи-то права на объекты авторского права. Из своей жизни, в СМИ, в интернете. Не важно, главное, чтобы Вам он был интересен.

### ДЗ по товарным знакам

[Мое решение задания](тз.md).

> [INFO]
> Опять же, советую искать самостоятельно, ведь на следующей практике можно получить втрое больше баллов за поиск на скорость.

Выбрать любую крупную отечественную компанию. Войти в Поисковую платформу Роспатента. Провести поиск по товарным знакам компании. Составить портфолио знаков компании по форме:

1. Сколько ТЗ у компании всего. Какие виды знаков зарегистрированы (слово, изо, комби, иные)
2. В отношении каких товаров/услуг зарегистрированы ТЗ
3. Все ли продукты компании имеют свои товарные знаки? Есть ли ТЗ, по которым нет реальных продуктов на рынке?
4. Проверить через сервис WIPO MADRID MONITOR, охраняются ли знаки за рубежом. Если да, то в каких странах.
5. Дать рекомендации компании по дальнейшей охране знаков.
