# Промпт для подготовки к экзамену от Блейхер

🔹 Загрузите в [deepseek](https://www.deepseek.com/)                                                                   
🔹 Загрузите файлы ниже.
🔹 В начале консультации вы узнаете структуру экзамена (тестовый блок + теория и задача).
🔹 Выберите темы из предложенного списка и работайте по одной теме за раз.
🔹 Каждая тема разбирается по схеме: теория → практика → вопросы.
🔹 Вопросы — важная часть подготовки, задавайте их сразу.
🔹 В конце можно пройти пробный экзамен без оценки, чтобы понять уровень готовности.

Промпт помогает выстроить подготовку системно и осознанно.
